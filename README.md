# Dhanisha Portfolio — Divo.

A responsive personal portfolio built with **HTML, CSS and vanilla JavaScript**. It is designed to work cleanly across mobile, tablet, laptop and desktop screens with both light and dark themes.

## Features
- Responsive navigation with mobile menu
- Light/dark theme with localStorage
- Large, readable portfolio hero section
- About, skills and learning journey sections
- Project search and category filters
- Accessible project details modal
- Scroll reveal and progress indicator
- Contact form validation and local draft saving
- Multiple submitted-message history stored locally in the browser
- View, hide, delete one message, or delete all messages
- Keyboard-friendly controls and reduced-motion support
- SEO metadata and SVG favicon

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## Run locally
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Contact-message note
The contact form is currently a **front-end demo**. Messages are stored in the visitor's browser using `localStorage`; they are not sent to an email inbox or server.
